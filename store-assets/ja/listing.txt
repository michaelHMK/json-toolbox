名前
JSON Toolbox

概要
高速な JSON ツール：整形、圧縮、エスケープ、比較をローカルで処理。広告・追跡・データ収集はありません。

詳細な説明
JSON Toolbox は、ブラウザの専用タブで JSON の整形、閲覧、比較を行える拡張機能です。完全にオフラインで動作し、アカウントや追加の権限は必要ありません。

整形と閲覧
- インデントを 2 スペース、4 スペース、タブから選んで JSON を整形できます。
- 構文エラーの行・列番号を表示し、該当箇所へ移動できます。ブラウザが位置情報を返さない場合は、ローカルの検証で補います。
- 折りたたみ可能なツリー表示で、仮想スクロール、階層ごとの展開、キーや値の検索、一致箇所への移動ができます。
- 結果全体をワンクリックでコピーできます。

ローカルファイルの読み込み
- 整形ページと圧縮ページで、ファイルを選択するか入力欄にドラッグ＆ドロップできます。
- UTF-8 の .json ファイルを一度に 1 つ、最大 50 MiB まで読み込めます。読み込み後は整形または圧縮を自動実行します。
- 約 200 万文字を超える入力は、読み取り専用の仮想プレビューで表示します。処理と結果のコピーには引き続き内容全体を使用します。

圧縮・エスケープ・エスケープ解除
- サイドバーから各ツールの専用ページに切り替えられます。
- 不要な空白を取り除いて JSON を 1 行に圧縮します。不正な JSON はエラーを表示し、位置情報がある場合はその場所も示します。
- JSON 文字列に埋め込めるようテキストをエスケープしたり、エスケープ済み文字列を元のテキストに戻したりして、結果をコピーできます。

JSON の比較
- 追加、削除、値の変更、型の変更をパスごとに確認できます。
- 配列はインデックスで比較するか、id などのキーフィールドで要素を対応付けられます。
- タイムスタンプなど、指定したパスを比較対象から除外できます。
- ツリー全体で差分を強調表示するか、差分のみを表示し、差分間を移動できます。
- 整形後の JSON を行単位で比較するテキスト表示にも切り替えられます。

外観
- サイドバーでサムネイルを確認しながら「通常」「目に優しい」「ダーク」を選べます。既定は「通常」です。
- テーマの選択だけをローカルに保存し、ツールの切り替えや再起動後に復元します。入力や結果は保存しません。

プライバシー
処理はすべてブラウザ内で完結します。データの収集やアップロード、ネットワーク通信、リモートコード、広告、追跡はありません。入力履歴は保存しません。コピー操作を行ったときだけ結果をシステムのクリップボードに書き込みます。

入力と結果の全体はメモリに保持されるため、処理性能は端末とデータ構造に依存します。仮想表示では一度に内容の一部だけを描画するため、ブラウザ標準の検索は描画済みの部分のみが対象です。必要に応じてツリー検索や結果全体のコピーを利用してください。差分が多い場合、一致しないテキストの範囲をブロック単位で表示することがあります。
