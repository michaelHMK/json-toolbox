名前
JSON Toolbox - JSON 整形・ビューア・比較・YAML 変換

概要
ローカル完結の JSON / JSON5 整形、ツリー表示、構造比較、YAML 双方向変換。50 MiB ファイルと API ページ表示に対応。広告・追跡なし。

詳細な説明
JSON Toolbox は、オフラインで動作する高速な JSON 整形、JSON ビューア、JSON 比較、YAML 変換ツールです（JSONC・JSON5 対応）。インストール時のサイト権限要求や警告はなく、アカウントも不要です。

整形・閲覧と JSONC / JSON5
- 2 スペース、4 スペース、タブからインデントを選び、大きな整数や小数の精度を保ったまま JSON を整形できます。
- 厳格な JSON 解析で失敗した場合、コメント・末尾カンマ・シングルクォート・クォートなしキー・16 進数を含む JSONC / JSON5 として自動的にフォールバック解析します。
- 構文エラーの行・列番号と移動リンクを表示（ブラウザが返さない場合はローカル検証で補完）。
- 仮想スクロール対応の折りたたみツリー、階層展開、キー・値検索、一致箇所ナビゲーション、ワンクリックコピーに対応。

JSON <-> YAML 双方向変換
- JSON から YAML 1.2 への変換と YAML から JSON への変換を専用ページで提供（数値精度保持、マルチドキュメント YAML 対応、エイリアス制限による安全処理）。
- ワンクリックで変換方向を切り替えられます。

Web ページの JSON 自動整形と右クリックメニュー
- ページ上のテキストを選択して右クリック「JSON 工具箱 / JSON Toolbox で選択内容を開く」からすぐに整形できます。
- 任意のページで右クリック「このページの JSON を整形」を実行すると、activeTab のみを使ってオンデマンドで整形表示します。
- サイドバーの「JSON ページを自動整形」スイッチは初期状態でオフです。オンにした場合のみ任意のホスト権限を要求し、API 応答などをツリー表示（原文/整形切替・コピー・ツールで開く・任意の text/plain 対応）にします。

ローカルファイルの読み込み
- 7 つのツールすべてでファイル選択やドラッグ＆ドロップに対応（JSON/比較ページは .json 最大 50 MiB、YAML→JSON は .yaml / .yml 最大 10 MiB、UTF-8）。
- 大容量ファイルや長いテキストの貼り付けはエディタで直接開き、編集・全文コピーが可能です。

圧縮・エスケープ・エスケープ解除
- サイドバーから専用ツールを切り替え、1 行圧縮（JSONC/JSON5 対応）や文字列エスケープ／解除を実行できます。

JSON の比較
- パスごとの追加・削除・値変更・型変更を構造化表示し、インデックス一致または id などのキー一致、除外パス指定、差分のみ表示、行単位テキスト差分に対応します。

外観とプライバシー
- サイドバーで「通常」「目に優しい」「ダーク」を選択でき、埋め込みビューアにも反映されます。保存されるのはテーマ設定と任意の text/plain 設定のみで、データ収集・通信・広告・追跡は一切ありません。

入力と結果の全体はメモリに保持されるため、処理性能は端末とデータ構造に依存します。仮想表示では一度に内容の一部だけを描画するため、ブラウザ標準の検索は描画済みの部分のみが対象です。必要に応じてツリー検索や結果全体のコピーを利用してください。差分が多い場合、一致しないテキストの範囲をブロック単位で表示することがあります。
