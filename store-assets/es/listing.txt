Nombre
JSON Toolbox - Formateador, Visor, Diff y YAML

Descripción breve
Formateador, visor, diff JSON/JSON5 y conversor YAML local. Soporta archivos de 50 MiB y páginas API sin conexión ni rastreo.

Descripción detallada
JSON Toolbox es un formateador JSON, visor JSON, comparador JSON y conversor JSON a YAML rápido sin conexión compatible con JSONC y JSON5 en una pestaña dedicada. No solicita acceso a sitios web al instalarse, sin avisos de permisos ni cuentas.

Formatear, explorar y JSONC / JSON5
- Formatea JSON con sangría de 2 espacios, 4 espacios o tabulaciones conservando la precisión exacta de enteros grandes y decimales.
- Cambia automáticamente de JSON estricto a JSONC / JSON5 cuando hay comentarios, comas finales, comillas simples, claves sin comillas o números hexadecimales.
- Consulta errores de sintaxis con línea, columna y navegación a la posición, más respaldo local cuando el navegador no la indica.
- Explora un árbol virtual plegable con expansión por nivel, búsqueda de claves o valores y copia en un clic.

Conversión bidireccional JSON <-> YAML
- Convierte JSON a YAML 1.2 y YAML a JSON conservando la precisión numérica, con soporte para YAML multidocumento y protección contra alias excesivos.
- Invierte la dirección de conversión con un clic.

Páginas JSON automáticas y menú contextual
- Selecciona texto en cualquier página y pulsa clic derecho → «Abrir selección en JSON Toolbox».
- Formatea bajo demanda la pestaña actual mediante «Formatear JSON en esta página» usando activeTab sin permisos permanentes.
- El interruptor opcional «Formatear páginas JSON automáticamente» viene desactivado de fábrica y solo pide permisos opcionales al activarlo, con vista Original / Formateado, copia, abrir en la herramienta y opción text/plain.

Importar archivos locales
- En las siete herramientas, selecciona o arrastra un archivo UTF-8 (.json de hasta 50 MiB; .yaml/.yml de hasta 10 MiB en YAML -> JSON).
- Los archivos grandes o textos largos se abren directamente en el editor para editar y copiar por completo.

Minificar, escapar y comparar JSON
- Minificación en una línea (con JSONC/JSON5), escape/desescape de cadenas JSON y diff estructural por rutas (por índice o campo clave como id, rutas ignoradas, solo diferencias y comparación de texto línea por línea).

Apariencia y privacidad
- Elige Normal, Confort u Oscuro en la barra lateral (compartido con el visor integrado). Todo se procesa localmente en memoria: sin subidas, solicitudes de red, anuncios ni rastreo.

Las entradas y los resultados completos permanecen en memoria; el rendimiento depende del dispositivo y de la estructura de los datos. Las vistas virtuales solo muestran parte del contenido a la vez, por lo que la búsqueda nativa del navegador solo abarca la parte representada. Usa la búsqueda del árbol o copia el resultado completo cuando lo necesites. Si hay muchas diferencias, las secciones de texto no coincidentes pueden mostrarse como bloques completos.
