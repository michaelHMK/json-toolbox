Nazwa
JSON Toolbox - Formatowanie, Podgląd, Diff i YAML

Krótki opis
Lokalny formater, podgląd, diff JSON/JSON5 i konwerter YAML. Obsługuje pliki 50 MiB oraz strony API offline bez śledzenia.

Szczegółowy opis
JSON Toolbox to szybki, działający offline program do formatowania JSON, podglądu JSON, porównywania JSON i konwersji JSON na YAML z obsługą JSONC i JSON5 w osobnej karcie przeglądarki. Nie wymaga uprawnień do stron podczas instalacji, nie wyświetla ostrzeżeń i nie wymaga konta.

Formatowanie, przeglądanie i JSONC / JSON5
- Formatuj JSON z wcięciami 2 lub 4 spacji albo tabulatorów z pełnym zachowaniem precyzji dużych liczb całkowitych i dziesiętnych.
- Automatycznie przełącza się ze ścisłego JSON na JSONC / JSON5 przy komentarzach, końcowych przecinkach, pojedynczych cudzysłowach, kluczach bez cudzysłowów i liczbach szesnastkowych.
- Wyświetla błędy składni z numerem wiersza i kolumny oraz nawigacją do błędu, rozwijane drzewo wirtualne, wyszukiwanie kluczy i wartości oraz kopiowanie jednym kliknięciem.

Dwukierunkowa konwersja JSON <-> YAML
- Konwertuj JSON na YAML 1.2 oraz YAML na JSON z zachowaniem precyzji liczb, obsługą wielodokumentowych strumieni YAML i ochroną przed zapętlonymi aliasami.
- Odwracaj kierunek konwersji bezpośrednio w narzędziu.

Automatyczne formatowanie stron JSON i menu kontekstowe
- Zaznacz tekst na dowolnej stronie i kliknij prawym przyciskiem „Otwórz zaznaczenie w JSON Toolbox”.
- Używaj na żądanie opcji „Formatuj JSON na tej stronie” przez activeTab bez nadawania stałych uprawnień witrynom.
- Opcjonalny przełącznik „Automatycznie formatuj strony JSON” na pasku bocznym jest domyślnie WYŁĄCZONY i prosi o opcjonalne uprawnienia dopiero po włączeniu (z widokiem Oryginał / Sformatowany, kopiowaniem, otwarciem w narzędziu i opcją text/plain).

Import lokalnych plików, minifikacja i porównywanie JSON
- We wszystkich siedmiu narzędziach importuj pliki UTF-8 (.json do 50 MiB; .yaml/.yml do 10 MiB w YAML -> JSON).
- Minifikuj do jednej linii (także JSONC/JSON5), dodawaj/cofaj sekwencje ucieczki i porównuj strukturę według indeksu lub klucza id, ignorując wybrane ścieżki i przełączając na diff tekstowy.

Wygląd i prywatność
- Wybierz motyw Normalny, Komfort oczu lub Ciemny (współdzielony z wbudowaną przeglądarką stron). Całe przetwarzanie odbywa się lokalnie w pamięci: bez wysyłania danych, żądań sieciowych, reklam i śledzenia.

Duże dane wejściowe i wyniki pozostają w pamięci; wydajność zależy od urządzenia i struktury danych. Widoki wirtualne renderują jednocześnie tylko część zawartości, dlatego wbudowane wyszukiwanie przeglądarki obejmuje wyłącznie wyrenderowaną część. W razie potrzeby użyj wyszukiwania w drzewie lub skopiuj cały wynik. Przy rozległych różnicach tekstowych niedopasowane fragmenty mogą być wyświetlane jako całe bloki.
