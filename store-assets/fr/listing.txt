Nom
JSON Toolbox - Formateur, Visionneuse, Diff & YAML

Description courte
Formateur, visionneuse, diff JSON/JSON5 et convertisseur YAML local. Gère fichiers de 50 Mio et API hors ligne, sans suivi.

Description détaillée
JSON Toolbox est un formateur JSON, une visionneuse JSON, un outil de comparaison JSON et un convertisseur JSON vers YAML rapide fonctionnant hors ligne (avec prise en charge JSONC et JSON5). Aucune autorisation d'accès aux sites n'est demandée à l'installation, sans avertissement ni compte requis.

Formater, parcourir et JSONC / JSON5
- Formatez le JSON avec 2 ou 4 espaces ou tabulations tout en préservant exactement les grands entiers et décimaux.
- Bascule automatiquement du JSON strict vers JSONC / JSON5 pour analyser commentaires, virgules finales, guillemets simples, clés sans guillemets et entiers hexadécimaux.
- Affichez les erreurs de syntaxe avec ligne, colonne, navigation directe et repli local lorsque le navigateur omet la position.
- Parcourez une arborescence virtuelle repliable avec déploiement par niveau, recherche clé/valeur, navigation entre résultats et copie en un clic.

Conversion bidirectionnelle JSON <-> YAML
- Convertissez JSON en YAML 1.2 et YAML en JSON dans des vues dédiées tout en préservant la précision des nombres et les flux YAML multi-documents.
- Inversez le sens de conversion directement depuis l'outil.

Formatage automatique de pages JSON et menu contextuel
- Sélectionnez du texte sur n'importe quelle page et faites clic droit → « Ouvrir la sélection dans JSON Toolbox ».
- Formatez une page JSON à la demande via le menu contextuel « Formater le JSON de cette page » grâce à activeTab, sans permission permanente.
- L'interrupteur optionnel « Formater automatiquement les pages JSON » est désactivé par défaut ; il ne demande les permissions optionnelles qu'à l'activation, avec bascule Brut / Formaté, copie, ouverture dans l'outil et option text/plain.

Importer des fichiers locaux
- Dans les sept outils, importez un fichier UTF-8 par sélection ou glisser-déposer (.json jusqu'à 50 Mio ; .yaml/.yml jusqu'à 10 Mio pour YAML -> JSON).
- Les fichiers volumineux et longs textes s'ouvrent directement dans l'éditeur pour une édition et une copie complètes.

Minifier, échapper et comparer du JSON
- Minification sur une ligne (avec JSONC/JSON5), échappement/déséchappement de chaînes JSON et diff structurel complet (par indice ou champ clé id, chemins ignorés, vue différences seules et diff texte ligne par ligne).

Apparence et confidentialité
- Choisissez Normal, Confort ou Sombre (synchronisé avec la visionneuse intégrée). Tout reste traité localement en mémoire : aucune collecte, aucune requête réseau, aucune publicité et aucun suivi.

Les données et résultats complets restent en mémoire ; les performances dépendent de l’appareil et de la structure des données. Les vues virtuelles n’affichent qu’une partie du contenu à la fois : la recherche native du navigateur ne couvre que cette partie. Utilisez la recherche dans l’arborescence ou copiez le résultat complet si nécessaire. En cas de différences textuelles importantes, les sections non correspondantes peuvent être affichées par blocs entiers.
