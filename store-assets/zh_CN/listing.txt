名称
JSON 工具箱

简短描述
高性能 JSON 工具箱：格式化、压缩、转义与去转义、树形搜索、结构与文本对比。数据仅在本地处理，无广告、无追踪、不收集数据。

详细描述
JSON 工具箱让你在独立浏览器标签页中格式化、查看和比较 JSON。完全离线运行，无需登录或申请额外权限。

格式化与浏览
- 美化 JSON，支持 2 空格、4 空格或 Tab 缩进。
- 提示语法错误；浏览器提供位置信息时显示行列号并定位。
- 树形折叠视图支持虚拟滚动、按层级展开、key/值搜索高亮和逐条跳转。
- 一键复制完整结果。

导入本地文件
- 格式化和压缩页面支持通过文件选择器选择文件，或拖放到输入区。
- 每次导入一个 UTF-8 编码的 .json 文件，最大 50 MiB；导入后自动执行格式化或压缩。
- 超过约 200 万字符的输入使用只读虚拟预览，仍使用完整内容处理和复制结果。

压缩、转义与去转义
- 每个工具使用独立页面，通过侧边栏切换。
- 去除多余空白，将 JSON 压缩为单行；无效 JSON 会提示错误，并在可用时显示错误位置。
- 将文本转为可嵌入 JSON 的字符串内容，或将转义后的字符串还原为原始文本，再复制结果。

JSON 对比
- 按路径查看结构差异：新增、删除、值变化和类型变化。
- 数组支持按下标对比，或按 id 等字段配对。
- 可忽略指定路径，例如时间戳字段。
- 在完整树中高亮差异，或只显示差异，并逐处导航。
- 可切换到格式化后的逐行文本对比。

隐私
所有处理在浏览器本地完成，不收集或上传数据，不发起网络请求，不加载远程代码，无广告或追踪。不保存输入历史，仅在你执行复制时将结果写入系统剪贴板。

完整输入与结果仍保留在内存中，实际性能取决于设备和数据结构。虚拟视图每次仅渲染部分内容，浏览器原生查找只覆盖已渲染部分；需要时可使用树搜索或复制完整结果。较大的文本差异可能按整块展示。
