الاسم
JSON Toolbox

الوصف المختصر
أدوات JSON سريعة للتنسيق والتصغير والتهريب والمقارنة محليًا. بلا إعلانات أو تتبع أو جمع للبيانات.

الوصف التفصيلي
تتيح لك إضافة JSON Toolbox تنسيق JSON واستعراضه ومقارنته في علامة تبويب مستقلة في المتصفح. تعمل بالكامل دون اتصال بالإنترنت، ولا تتطلب حسابًا أو أذونات إضافية.

التنسيق والاستعراض
- نسّق JSON بمسافة بادئة من مسافتين أو أربع مسافات أو علامة جدولة.
- اعرض أخطاء الصياغة مع رقم السطر والعمود والانتقال إلى موضع الخطأ عندما يوفر المتصفح هذه المعلومات.
- استعرض شجرة قابلة للطي مع تمرير افتراضي، وتوسيع حسب المستوى، والبحث عن المفاتيح والقيم والتنقل بين النتائج المطابقة.
- انسخ النتيجة كاملة بنقرة واحدة.

استيراد الملفات المحلية
- في صفحتَي التنسيق والتصغير، اختر ملفًا أو اسحبه وأفلته في منطقة الإدخال.
- استورد ملف .json واحدًا بترميز UTF-8 في كل مرة، بحجم لا يتجاوز 50 MiB. يبدأ التنسيق أو التصغير تلقائيًا بعد الاستيراد.
- يُعرض الإدخال الذي يتجاوز نحو مليوني محرف في معاينة افتراضية للقراءة فقط. تظل المعالجة ونسخ النتيجة معتمدين على المحتوى الكامل.

التصغير والتهريب وفك التهريب
- انتقل بين الأدوات من الشريط الجانبي.
- أزل المسافات البيضاء غير الضرورية لتحويل JSON إلى سطر واحد. تظهر رسالة عند وجود JSON غير صالح، مع موضع الخطأ إن توفر.
- حوّل النص إلى محتوى بمحارف هروب لإدراجه في سلسلة JSON، أو استعد النص الأصلي من سلسلة تحتوي على محارف هروب، ثم انسخ النتيجة.

مقارنة JSON
- اعرض الفروق البنيوية حسب المسار: الإضافات والحذف وتغييرات القيم والأنواع.
- قارن المصفوفات حسب الفهرس أو طابق عناصرها باستخدام حقل مفتاح مثل id.
- تجاهل مسارات محددة، مثل حقول الطوابع الزمنية.
- استعرض الشجرة كاملة مع تمييز الفروق، أو اعرض الفروق فقط وتنقل بينها.
- انتقل إلى مقارنة نصية سطرًا بسطر بعد تنسيق JSON.

الخصوصية
تجري جميع العمليات محليًا داخل المتصفح. لا جمع للبيانات أو رفع لها، ولا طلبات شبكة أو شيفرة بعيدة أو إعلانات أو تتبع. لا يُحفظ سجل الإدخال. لا تُكتب النتيجة في حافظة النظام إلا عند تنفيذ النسخ.

يبقى الإدخال والنتائج بالكامل في الذاكرة، ويعتمد الأداء على الجهاز وبنية البيانات. تعرض الواجهات الافتراضية جزءًا من المحتوى في كل مرة، لذلك لا يشمل بحث المتصفح المدمج إلا الجزء المعروض. استخدم البحث في الشجرة أو انسخ النتيجة كاملة عند الحاجة. قد تُعرض الفروق النصية الكبيرة على هيئة كتل كاملة.
