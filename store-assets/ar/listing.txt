JSON Toolbox - منسق وعارض ومقارنة JSON و YAML

الوصف المختصر
منسق وعارض ومقارنة JSON وJSON5 ومحول YAML محلي. يعالج ملفات 50 MiB وصفحات API دون اتصال أو تتبع أو إعلانات.

الوصف التفصيلي
JSON Toolbox هو منسق JSON وعارض JSON وأداة مقارنة JSON ومحول JSON إلى YAML سريع ويعمل محليًا دون اتصال بالإنترنت مع دعم JSONC وJSON5 في علامة تبويب مستقلة. لا يطلب أي أذونات للمواقع عند التثبيت، بلا تحذيرات وبلا حساب.

التنسيق والاستعراض ودعم JSONC / JSON5
- نسّق JSON بمسافة بادئة من مسافتين أو أربع مسافات أو علامة جدولة مع الحفاظ التام على دقة الأعداد الصحيحة الكبيرة والأرقام العشرية.
- ينتقل تلقائيًا من JSON الصارم إلى تحليل JSONC / JSON5 عند وجود تعليقات أو فواصل زائدة أو علامات تنصيص مفردة أو مفاتيح بلا اقتباس أو أرقام ست عشرية.
- يعرض أخطاء الصياغة مع رقم السطر والعمود والانتقال للموضع، مع دعم استعراض شجرة افتراضية والبحث عن المفاتيح والقيم والنسخ بنقرة واحدة.

التحويل الثنائي JSON <-> YAML
- حوّل JSON إلى YAML 1.2 أو YAML إلى JSON مع الحفاظ على دقة الأرقام ودعم مستندات YAML المتعددة والحماية من الأسماء المستعارة الزائدة أو الدائرية، مع تبديل الاتجاه بسهولة.

تنسيق صفحات الويب وقائمة النقر بزر الفأرة الأيمن
- حدد أي نص على صفحة ويب واختر «فتح التحديد في JSON Toolbox».
- استخدم «تنسيق JSON في هذه الصفحة» عند الحاجة عبر activeTab دون منح صلاحيات دائمة.
- مفتاح «تنسيق صفحات JSON تلقائيًا» في الشريط الجانبي متوقف افتراضيًا ولا يطلب صلاحية المواقع الاختيارية إلا عند تفعيله، مع التبديل بين النص الأصلي والمنسق والنسخ وخيار text/plain الاختياري.

استيراد الملفات المحلية والتصغير والتهريب والمقارنة
- في جميع الأدوات السبع، استورد ملفات UTF-8: حتى 50 MiB لملفات .json، وحتى 10 MiB لملفات .yaml / .yml في YAML -> JSON.
- صغّر JSON إلى سطر واحد، وأدر أحرف الهروب أو أزلها، وقارن البنية والنصوص حسب الفهرس أو حقل المفتاح مع تجاهل المسارات المحددة.

المظهر والخصوصية
- اختر المظهر العادي أو المريح للعين أو الداكن (متزامن مع العارض المدمج). تجري جميع العمليات محليًا في الذاكرة دون طلبات شبكة أو جمع بيانات أو إعلانات أو تتبع.

يبقى الإدخال والنتائج بالكامل في الذاكرة، ويعتمد الأداء على الجهاز وبنية البيانات. تعرض الواجهات الافتراضية جزءًا من المحتوى في كل مرة، لذلك لا يشمل بحث المتصفح المدمج إلا الجزء المعروض. استخدم البحث في الشجرة أو انسخ النتيجة كاملة عند الحاجة. عند وجود فروق نصية كثيرة، قد تُعرض الأجزاء غير المتطابقة على هيئة كتل كاملة.
