Nome
JSON Toolbox - Formattatore, Viewer, Diff e YAML

Descrizione breve
Formattatore, visualizzatore, diff JSON/JSON5 e convertitore YAML locale. Gestisce file da 50 MiB e API offline senza tracciamento.

Descrizione dettagliata
JSON Toolbox è un formattatore JSON, visualizzatore JSON, strumento di confronto JSON e convertitore JSON in YAML veloce e offline con supporto JSONC e JSON5 in una scheda dedicata. Nessun permesso sui siti richiesto all'installazione, nessun avviso e nessun account necessario.

Formattare, esplorare e JSONC / JSON5
- Formatta JSON con 2 spazi, 4 spazi o tabulazioni mantenendo intatta la precisione di grandi interi e decimali.
- Passa automaticamente da JSON rigoroso a JSONC / JSON5 per gestire commenti, virgole finali, apici singoli, chiavi senza virgolette ed esadecimali.
- Visualizza gli errori di sintassi con riga, colonna e salto alla posizione, ed esplora un albero virtuale comprimibile con ricerca di chiavi/valori e copia in un clic.

Conversione bidirezionale JSON <-> YAML
- Converti JSON in YAML 1.2 e YAML in JSON preservando la precisione dei numeri, con supporto YAML multi-documento e protezione contro alias ciclici.
- Inverti la direzione di conversione direttamente nello strumento.

Formattazione automatica delle pagine JSON e menu contestuale
- Seleziona del testo su qualsiasi pagina e scegli dal menu contestuale «Apri selezione in JSON Toolbox».
- Usa su richiesta «Formatta JSON in questa pagina» tramite activeTab senza concedere permessi permanenti.
- L'interruttore opzionale «Formatta automaticamente le pagine JSON» nella barra laterale è disattivato per impostazione predefinita e richiede i permessi opzionali solo quando attivato, con vista Originale / Formattato, copia, apertura nello strumento e opzione text/plain.

Importare file locali, minificare, escape e confrontare
- In tutti e sette gli strumenti importa file UTF-8 fino a 50 MiB (.json e .yaml/.yml in YAML -> JSON).
- Minifica su una riga (anche JSONC/JSON5), applica o rimuovi escape delle stringhe e confronta strutture per indice o chiave (es. id) ignorando i percorsi scelti o in diff testuale.

Aspetto e privacy
- Scegli Normale, Riposo visivo o Scuro (sincronizzato con il visualizzatore integrato). Tutto avviene localmente in memoria: nessuna raccolta dati, nessuna richiesta di rete, nessuna pubblicità e nessun tracciamento.

Gli input e i risultati completi restano in memoria; le prestazioni dipendono dal dispositivo e dalla struttura dei dati. Le viste virtuali mostrano solo una parte del contenuto alla volta, quindi la ricerca integrata del browser copre solo la parte visualizzata. Usa la ricerca nell’albero o copia il risultato completo quando necessario. In caso di differenze testuali estese, le sezioni non corrispondenti possono essere mostrate come blocchi interi.
