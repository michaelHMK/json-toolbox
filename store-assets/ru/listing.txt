Название
JSON Toolbox

Краткое описание
Быстрые инструменты JSON: форматирование, сжатие, экранирование и сравнение локально. Без рекламы, слежки и сбора данных.

Подробное описание
JSON Toolbox позволяет форматировать, просматривать и сравнивать JSON в отдельной вкладке браузера. Расширение работает полностью офлайн, без учётной записи и дополнительных разрешений.

Форматирование и просмотр
- Форматируйте JSON, используя для отступов 2 пробела, 4 пробела или символ табуляции.
- Просматривайте синтаксические ошибки с указанием строки, столбца и переходом к месту ошибки, если браузер предоставляет сведения о позиции.
- Используйте сворачиваемое дерево с виртуальной прокруткой, раскрытием по уровням, поиском ключей и значений и переходами между совпадениями.
- Копируйте полный результат одним нажатием.

Импорт локальных файлов
- На страницах форматирования и сжатия выберите файл или перетащите его в область ввода.
- Импортируйте по одному файлу .json в кодировке UTF-8 размером до 50 MiB. После импорта форматирование или сжатие запускается автоматически.
- Если длина ввода превышает примерно два миллиона символов, содержимое отображается в виртуальном предпросмотре только для чтения. Обработка и копирование результата по-прежнему используют полное содержимое.

Сжатие, экранирование и снятие экранирования
- Переключайтесь между инструментами с помощью боковой панели.
- Удаляйте лишние пробельные символы, чтобы получить JSON в одну строку. Для некорректного JSON выводится сообщение об ошибке с позицией, если она доступна.
- Экранируйте текст для включения в строку JSON или восстанавливайте исходный текст из экранированной строки, затем копируйте результат.

Сравнение JSON
- Просматривайте структурные различия по путям: добавления, удаления, изменения значений и типов.
- Сравнивайте массивы по индексу или сопоставляйте элементы по ключевому полю, например id.
- Исключайте выбранные пути, например поля с временными метками.
- Просматривайте полное дерево с выделенными различиями или только различия и переходите между ними.
- Переключайтесь на построчное текстовое сравнение отформатированного JSON.

Конфиденциальность
Вся обработка выполняется локально в браузере. Нет сбора или отправки данных на сервер, сетевых запросов, удалённого кода, рекламы или слежения. История ввода не сохраняется. Результат записывается в системный буфер обмена только при копировании.

Полный ввод и результаты остаются в памяти; производительность зависит от устройства и структуры данных. Виртуальные представления отображают только часть содержимого за раз, поэтому встроенный поиск браузера охватывает лишь отображённую часть. При необходимости используйте поиск по дереву или копируйте полный результат. Большие текстовые различия могут отображаться целыми блоками.
