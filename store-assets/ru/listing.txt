Название
JSON Toolbox — Форматирование, Просмотр, Сравнение и YAML

Краткое описание
Локальный форматтер, просмотр, сравнение JSON/JSON5 и конвертер YAML. Файлы до 50 МиБ и страницы API офлайн, без слежки.

Подробное описание
JSON Toolbox — быстрый локальный инструмент для форматирования JSON, просмотра JSON, сравнения JSON и конвертации JSON в YAML с поддержкой JSONC и JSON5 на отдельной вкладке. При установке не запрашиваются права доступа к сайтам, без предупреждений и регистрации.

Форматирование, просмотр и JSONC / JSON5
- Форматируйте JSON с отступом 2 пробела, 4 пробела или табуляцией, сохраняя точность больших целых чисел и десятичных дробей.
- Автоматический переход от строгого JSON к JSONC / JSON5 при наличии комментариев, висячих запятых, одинарных кавычек, ключей без кавычек и шестнадцатеричных чисел.
- Просматривайте ошибки синтаксиса с указанием строки, столбца и переходом к позиции.
- Используйте сворачиваемое виртуальное дерево с раскрытием по уровням, поиском ключей и значений и копированием в один клик.

Конвертация JSON <-> YAML
- Преобразуйте JSON в YAML 1.2 и YAML обратно в JSON с сохранением числовой точности, поддержкой многодокументного YAML и защитой от циклических и избыточных алиасов.
- Меняйте направление конвертации одним нажатием.

Автоформатирование веб-страниц и контекстное меню
- Выделите текст на любой странице и выберите в контекстном меню «Открыть выделение в JSON Toolbox».
- Используйте «Форматировать JSON на этой странице» по требованию через activeTab без постоянных прав на сайты.
- Переключатель «Автоматически форматировать страницы JSON» на боковой панели по умолчанию выключен и запрашивает опциональный доступ только при включении; есть переключение Оригинал / Форматированный вид, копирование, открытие в инструменте и опция text/plain.

Импорт локальных файлов
- Во всех семи инструментах загружайте или перетаскивайте UTF-8 файлы до 50 MiB (.json и .yaml / .yml для YAML -> JSON). Крупные файлы и длинный текст открываются напрямую в редакторе.

Сжатие, экранирование и сравнение JSON
- Сжатие в одну строку (с поддержкой JSONC/JSON5), экранирование и снятие экранирования, а также структурное сравнение (по индексу или ключу id, исключение путей, фильтр различий и построчный текстовый diff).

Оформление и конфиденциальность
- Темы «Обычный», «Комфорт» и «Тёмный» (синхронизированы со встроенным просмотрщиком). Вся обработка выполняется локально в памяти без сетевых запросов, сбора данных, рекламы и слежки.

Полный ввод и результаты остаются в памяти; производительность зависит от устройства и структуры данных. Виртуальные представления отображают только часть содержимого за раз, поэтому встроенный поиск браузера охватывает лишь отображённую часть. При необходимости используйте поиск по дереву или копируйте полный результат. При большом количестве различий несовпадающие участки текста могут отображаться целыми блоками.
