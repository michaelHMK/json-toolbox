名稱
JSON 工具箱

簡短說明
高效 JSON 工具箱：格式化、壓縮、轉義及取消轉義、樹狀搜尋、結構與文字比較。數據只在本機處理，無廣告、無追蹤、不收集數據。

詳細說明
JSON 工具箱讓你在獨立的瀏覽器分頁中格式化、檢視及比較 JSON。完全離線運作，無須登入或申請額外權限。

格式化與瀏覽
- 美化 JSON，支援 2 個空格、4 個空格或 Tab 縮排。
- 提示語法錯誤，顯示行列編號並跳至錯誤位置；瀏覽器未提供位置時，由本機驗證補充。
- 可摺疊的樹狀檢視支援虛擬捲動、按層級展開、搜尋鍵或值，以及逐項跳至符合項目。
- 一鍵複製完整結果。

匯入本機檔案
- 格式化及壓縮頁面支援透過檔案選擇器選取檔案，或拖放至輸入區。
- 每次匯入一個 UTF-8 編碼的 .json 檔案，最大 50 MiB；匯入後自動執行格式化或壓縮。
- 超過約 200 萬字元的輸入採用唯讀虛擬預覽，處理及複製結果仍使用完整內容。

壓縮、轉義及取消轉義
- 每個工具都有獨立頁面，可透過側邊欄切換。
- 移除多餘空白，將 JSON 壓縮為單行；無效的 JSON 會顯示錯誤，並在取得位置資訊時標示位置。
- 將文字轉換為可嵌入 JSON 的字串內容，或將轉義後的字串還原為原始文字，再複製結果。

JSON 比較
- 按路徑檢視結構差異：新增、刪除、值變更及類型變更。
- 陣列支援按索引比較，或按 id 等鍵欄位配對。
- 可忽略指定路徑，例如時間戳記欄位。
- 在完整樹狀檢視中標示差異，或只顯示差異，並逐項跳轉。
- 可切換至格式化後的逐行文字比較。

外觀
- 在側邊欄查看縮圖預覽，選擇正常、護眼或暗色模式；預設為正常模式。
- 只在本機記住主題選擇，切換工具頁或重新開啟後還原，不儲存輸入及結果。

私隱
所有處理都在瀏覽器本機完成，不收集或上載數據、不發出網絡請求、不載入遠端程式碼，沒有廣告或追蹤。不儲存輸入記錄，只有執行複製時才會將結果寫入系統剪貼簿。

完整輸入及結果仍保留在記憶體中，實際效能取決於裝置及數據結構。虛擬檢視每次只繪製部分內容，瀏覽器內建尋找只涵蓋已繪製的部分；需要時可使用樹狀搜尋或複製完整結果。差異較多時，未匹配的文字區間可能以整個區塊顯示。
