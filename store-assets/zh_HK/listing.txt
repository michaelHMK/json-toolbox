名稱
JSON 工具箱 - 格式化、樹狀檢視、比較與 YAML 轉換

簡短說明
本機 JSON/JSONC/JSON5 格式化、樹狀檢視、Diff 比較與 YAML 轉換，支援 50 MiB 大檔與網頁 JSON 檢視。無廣告無追蹤。

詳細說明
JSON 工具箱是一款高效本機 JSON 格式化、JSON 檢視、JSON 比較與 YAML 轉換擴充功能，兼容 JSONC 與 JSON5，並在獨立分頁與網頁中離線運行。預設安裝零網站權限、零權限警告、無須登入。

格式化、瀏覽與 JSONC / JSON5
- 美化 JSON，支援 2 個空格、4 個空格或 Tab 縮排，完整保留大整數及小數精度。
- 嚴格 JSON 解析失敗時自動改用 JSONC / JSON5 寬鬆解析，支援註釋、結尾逗號、單引號字串、無引號鍵名及十六進制整數。
- 提示語法錯誤並顯示行列編號與跳轉；瀏覽器未提供位置時由本機驗證補充。
- 可摺疊樹狀檢視支援虛擬捲動、按層級展開、搜尋鍵或值及一鍵複製全文。

JSON <-> YAML 雙向轉換
- 提供 JSON 轉 YAML 1.2 與 YAML 轉 JSON 雙向頁面，支援多文件 YAML 轉 JSON 陣列、防止循環或過量別名，並保留數字精度。
- 一鍵互換轉換方向。

網頁 JSON 自動格式化與右鍵選單
- 選取網頁文字並右鍵「在 JSON 工具箱中開啟所選內容」，即時載入並格式化。
- 在網頁右鍵點擊「格式化此頁 JSON」，只透過 activeTab 臨時格式化當前分頁。
- 側邊欄「自動格式化網頁中的 JSON」開關預設關閉；只在主動開啟後才申請可選網站權限，提供 原文 / 格式化 切換、複製、「在工具箱中開啟」及可選 text/plain 開關。

匯入本機檔案
- 七個工具頁面均可選擇檔案或拖放匯入（.json 最大 50 MiB；YAML 轉 JSON 的 .yaml / .yml 最大 10 MiB），UTF-8 編碼單檔匯入後自動執行。
- 大型檔案或貼上長文字直接在編輯器開啟，可修改與複製全文。

壓縮、轉義及取消轉義
- 透過側邊欄切換工具頁；移除空白壓縮為單行 JSON（兼支援 JSONC/JSON5）。
- 將文字轉義為 JSON 字串內容，或還原已轉義字串為原文。

JSON 比較
- 按路徑檢視新增、刪除、值及類型變更；陣列支援按索引或鍵欄位配對，可忽略指定路徑。
- 支援標示完整樹、只顯示差異及逐項跳轉，以及逐行文字比較。

外觀
- 在側邊欄切換正常、護眼或暗色模式（網頁檢視器同步套用），只在本機記住主題及純文字開關，不儲存輸入或結果。

私隱
所有處理均在本機瀏覽器記憶體內完成，不收集或上載數據、無網絡請求與追蹤。預設不讀取網頁內容；右鍵功能與可選自動模式只在你明確觸發或開啟時處理，不保留網頁數據。

完整輸入及結果仍保留在記憶體中，實際效能取決於裝置及數據結構。虛擬檢視每次只繪製部分內容，瀏覽器內建尋找只涵蓋已繪製的部分；需要時可使用樹狀搜尋或複製完整結果。差異較多時，未匹配的文字區間可能以整個區塊顯示。
