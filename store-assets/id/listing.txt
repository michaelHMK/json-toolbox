Nama
JSON Toolbox - Pemformat, Penampil, Diff & YAML

Deskripsi singkat
Pemformat, penampil, diff JSON/JSON5, dan konverter YAML lokal. Tangani file 50 MiB & halaman API offline tanpa pelacakan.

Deskripsi lengkap
JSON Toolbox adalah pemformat JSON, penampil JSON, pembanding JSON, dan konverter JSON ke YAML offline yang cepat dengan dukungan JSONC dan JSON5 di tab tersendiri. Tanpa permintaan izin situs web saat pemasangan, tanpa peringatan izin, dan tanpa akun.

Format, telusuri & JSONC / JSON5
- Rapikan JSON dengan indentasi 2 spasi, 4 spasi, atau Tab sambil mempertahankan presisi bilangan bulat besar dan desimal.
- Beralih otomatis dari JSON ketat ke penguraian JSONC / JSON5 yang toleran untuk komentar, koma akhir, kutipan tunggal, kunci tanpa kutip, dan heksadesimal.
- Lihat kesalahan sintaks beserta baris, kolom, dan navigasi ke posisi kesalahan, serta jelajahi pohon virtual dengan pencarian kunci/nilai dan salin sekali klik.

Konversi dua arah JSON <-> YAML
- Konversi JSON ke YAML 1.2 dan YAML kembali ke JSON dengan presisi angka tetap terjaga, dukungan YAML multi-dokumen, serta perlindungan alias.
- Balik arah konversi langsung dari alat.

Format otomatis halaman JSON & menu klik kanan
- Pilih teks di halaman mana pun lalu klik kanan "Buka pilihan di JSON Toolbox".
- Gunakan "Format JSON halaman ini" sesuai kebutuhan melalui activeTab tanpa izin situs permanen.
- Tombol opsional "Format halaman JSON secara otomatis" di bilah samping nonaktif secara default dan hanya meminta izin host opsional saat diaktifkan, lengkap dengan sakelar Asli / Diformat, Salin, Buka di alat, dan opsi text/plain.

Impor file lokal, minifikasi, escape & bandingkan
- Di ketujuh alat, pilih atau seret file UTF-8 (.json hingga 50 MiB; .yaml/.yml hingga 10 MiB pada YAML -> JSON).
- Minifikasi satu baris (termasuk JSONC/JSON5), escape/hapus escape string JSON, serta bandingkan struktur dan teks per baris dengan kunci pencocokan id dan jalur yang diabaikan.

Tampilan & Privasi
- Pilih tema Normal, Nyaman di mata, atau Gelap (berlaku juga di penampil tertanam). Semua pemrosesan berjalan lokal di memori tanpa unggahan, permintaan jaringan, iklan, atau pelacakan.

Masukan dan hasil berukuran besar tetap berada di memori; kinerja bergantung pada perangkat dan struktur data Anda. Tampilan virtual hanya merender sebagian konten pada satu waktu, sehingga fitur Cari bawaan browser hanya mencakup bagian yang dirender. Gunakan pencarian pohon atau salin hasil lengkap bila diperlukan. Untuk perbedaan teks yang luas, bagian yang tidak cocok dapat ditampilkan sebagai blok utuh.
