名稱
JSON 工具箱

簡短說明
高效能 JSON 工具箱：格式化、壓縮、跳脫與還原跳脫、樹狀搜尋、結構與文字比對。資料僅在本機處理，無廣告、無追蹤、不蒐集資料。

詳細說明
JSON 工具箱讓你在獨立的瀏覽器分頁中格式化、檢視及比對 JSON。完全離線運作，不需登入或申請額外權限。

格式化與瀏覽
- 美化 JSON，支援 2 個空格、4 個空格或 Tab 縮排。
- 提示語法錯誤；瀏覽器提供位置資訊時，顯示行列編號並跳至錯誤位置。
- 可摺疊的樹狀檢視支援虛擬捲動、依層級展開、搜尋鍵或值，以及逐筆跳至符合項目。
- 一鍵複製完整結果。

匯入本機檔案
- 格式化與壓縮頁面支援透過檔案選擇器選取檔案，或拖放至輸入區。
- 每次匯入一個 UTF-8 編碼的 .json 檔案，最大 50 MiB；匯入後自動執行格式化或壓縮。
- 超過約 200 萬字元的輸入採用唯讀虛擬預覽，處理與複製結果仍使用完整內容。

壓縮、跳脫與還原跳脫
- 每個工具都有獨立頁面，可透過側邊欄切換。
- 移除多餘空白，將 JSON 壓縮為單行；無效的 JSON 會顯示錯誤，並在可取得位置資訊時標示位置。
- 將文字轉換為可嵌入 JSON 的字串內容，或將含跳脫字元的字串還原為原始文字，再複製結果。

JSON 比對
- 依路徑檢視結構差異：新增、刪除、值變更及型別變更。
- 陣列支援依索引比對，或依 id 等鍵欄位配對。
- 可忽略指定路徑，例如時間戳記欄位。
- 在完整樹狀檢視中醒目標示差異，或僅顯示差異，並逐一導覽。
- 可切換至格式化後的逐行文字比對。

隱私
所有處理都在瀏覽器本機完成，不蒐集或上傳資料、不發出網路請求、不載入遠端程式碼，沒有廣告或追蹤。不儲存輸入歷程記錄，只有執行複製時才會將結果寫入系統剪貼簿。

完整輸入與結果仍保留在記憶體中，實際效能取決於裝置及資料結構。虛擬檢視每次只繪製部分內容，瀏覽器內建尋找只涵蓋已繪製的部分；需要時可使用樹狀搜尋或複製完整結果。較大的文字差異可能以整個區塊顯示。
