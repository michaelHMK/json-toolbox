名稱
JSON 工具箱 - 格式化、樹狀檢視、比對與 YAML 轉換

簡短說明
本機 JSON/JSONC/JSON5 格式化、樹狀檢視、Diff 比對與 YAML 轉換，支援 50 MiB 大檔與網頁 JSON 檢視。無廣告無追蹤。

詳細說明
JSON 工具箱是一款高效能本機 JSON 格式化、JSON 檢視、JSON 比對與 YAML 轉換擴充功能，支援 JSONC 與 JSON5，並在獨立分頁與網頁中離線運行。安裝時不請求任何網站權限、零警告、無需登入。

格式化、瀏覽與 JSONC / JSON5
- 美化 JSON，支援 2 個空格、4 個空格或 Tab 縮排，完整保留大整數與小數精度。
- 嚴格 JSON 解析失敗時自動切換至 JSONC / JSON5 寬鬆解析，支援註解、結尾逗號、單引號字串、無引號鍵名與十六進位整數。
- 提示語法錯誤並顯示行列編號與跳轉位置；瀏覽器未提供位置時由本機驗證補充。
- 可摺疊樹狀檢視支援虛擬捲動、依層級展開、搜尋鍵或值、逐筆跳轉與一鍵複製。

JSON <-> YAML 雙向轉換
- 提供 JSON 轉 YAML 1.2 與 YAML 轉 JSON 雙向工具頁，支援多文件 YAML 轉 JSON 陣列、防止循環或過量別名，並保留數字精度。
- 一鍵切換轉換方向。

網頁 JSON 自動格式化與右鍵選單
- 選取網頁文字並右鍵「在 JSON 工具箱中開啟選取內容」，即可載入格式化。
- 在任何網頁右鍵點擊「格式化此頁 JSON」，僅透過 activeTab 臨時格式化當前分頁。
- 側邊欄「自動格式化網頁中的 JSON」開關預設關閉；僅在主動開啟後才申請可選網站權限，提供 原文 / 格式化 切換、複製、「在工具箱中開啟」及可選 text/plain 開關。

匯入本機檔案
- 七個工具頁面皆支援選擇檔案或拖放匯入（.json，YAML 轉 JSON 支援 .yaml / .yml），UTF-8 編碼單檔最大 50 MiB，匯入後自動執行。
- 大型檔案或貼上長文字會直接在編輯器中開啟，可檢視與複製全文。

壓縮、跳脫與還原跳脫
- 透過側邊欄切換各工具頁面；移除空白壓縮成單行 JSON（相容 JSONC/JSON5）。
- 將文字轉為 JSON 字串內容，或將含跳脫字元的字串還原為原始文字。

JSON 比對
- 依路徑檢視新增、刪除、值與型別變更；陣列支援依索引或鍵欄位配對，並可忽略時間戳記等路徑。
- 支援高亮完整樹、僅顯示差異與逐一導覽，以及逐行文字比對。

外觀
- 在側邊欄切換正常、護眼或暗色模式（內嵌網頁檢視器同步套用），僅在本機記住主題與純文字子設定，不儲存輸入內容與結果。

隱私
所有處理均在本機瀏覽器記憶體中完成，不蒐集或上傳資料、無網路請求與追蹤。預設不存取網站資料；右鍵動作與可選自動模式僅在你的明確觸發或啟用時執行且不保留網頁資料。

完整輸入與結果仍保留在記憶體中，實際效能取決於裝置及資料結構。虛擬檢視每次只繪製部分內容，瀏覽器內建尋找只涵蓋已繪製的部分；需要時可使用樹狀搜尋或複製完整結果。差異較多時，未匹配的文字區間可能以整個區塊顯示。
