이름
JSON Toolbox

간단한 설명
빠른 JSON 도구: 포맷, 압축, 이스케이프, 비교를 기기에서 처리합니다. 광고, 추적, 데이터 수집이 없습니다.

상세 설명
JSON Toolbox는 별도의 브라우저 탭에서 JSON을 포맷하고 탐색하며 비교할 수 있는 확장 프로그램입니다. 완전히 오프라인으로 작동하며 계정이나 추가 권한이 필요하지 않습니다.

포맷 및 탐색
- 공백 2칸, 공백 4칸 또는 탭 들여쓰기로 JSON을 보기 좋게 정리합니다.
- 구문 오류의 행과 열 번호를 표시하고 해당 위치로 이동할 수 있습니다. 브라우저가 위치를 제공하지 않으면 로컬 검증으로 확인합니다.
- 접을 수 있는 트리 보기에서 가상 스크롤, 단계별 펼치기, 키와 값 검색, 검색 결과 간 이동을 지원합니다.
- 클릭 한 번으로 전체 결과를 복사합니다.

로컬 파일 가져오기
- 포맷 페이지와 압축 페이지에서 파일을 선택하거나 입력 영역으로 끌어다 놓을 수 있습니다.
- UTF-8 인코딩의 .json 파일을 한 번에 하나씩, 최대 50 MiB까지 가져옵니다. 가져온 후 포맷 또는 압축을 자동으로 실행합니다.
- 약 200만 자가 넘는 입력은 읽기 전용 가상 미리보기로 표시합니다. 처리와 결과 복사에는 계속 전체 내용을 사용합니다.

압축, 이스케이프 및 이스케이프 해제
- 사이드바에서 각 도구의 전용 페이지로 전환합니다.
- 불필요한 공백을 제거하여 JSON을 한 줄로 압축합니다. 올바르지 않은 JSON은 오류를 표시하며, 위치 정보가 있으면 함께 보여줍니다.
- 텍스트를 JSON 문자열에 넣을 수 있도록 이스케이프하거나 이스케이프된 문자열을 원래 텍스트로 복원한 뒤 결과를 복사할 수 있습니다.

JSON 비교
- 경로별로 추가, 삭제, 값 변경, 유형 변경 등 구조적 차이를 확인합니다.
- 배열을 인덱스로 비교하거나 id와 같은 키 필드로 항목을 연결합니다.
- 타임스탬프 필드 등 지정한 경로를 비교에서 제외할 수 있습니다.
- 전체 트리에서 차이를 강조 표시하거나 차이만 표시하고, 각 차이로 이동할 수 있습니다.
- 포맷된 JSON을 한 줄씩 비교하는 텍스트 보기로 전환할 수 있습니다.

모양
- 사이드바에서 축소 미리보기를 확인하며 기본, 눈 편안함, 다크 모드를 선택할 수 있습니다. 처음에는 기본 모드를 사용합니다.
- 테마 선택만 기기에 저장하여 도구를 전환하거나 다시 열 때 복원합니다. 입력과 결과는 저장하지 않습니다.

개인정보 보호
모든 처리는 브라우저 내에서 이루어집니다. 데이터 수집이나 업로드, 네트워크 요청, 원격 코드, 광고, 추적이 없습니다. 입력 기록을 저장하지 않습니다. 복사를 실행할 때만 결과를 시스템 클립보드에 기록합니다.

전체 입력과 결과는 메모리에 유지되며 성능은 기기와 데이터 구조에 따라 달라집니다. 가상 보기는 한 번에 내용의 일부만 렌더링하므로 브라우저 기본 찾기는 렌더링된 부분만 검색합니다. 필요하면 트리 검색을 사용하거나 전체 결과를 복사하세요. 차이가 많으면 일치하지 않는 텍스트 구간을 블록 단위로 표시할 수 있습니다.
