이름
JSON Toolbox - JSON 포맷터, 뷰어, 비교 및 YAML 변환

간단한 설명
로컬 전용 JSON / JSON5 포맷터, 트리 뷰어, 구조 비교 및 YAML 변환기. 50 MiB 대용량 파일과 API 페이지 포맷을 지원하며 추적이 없습니다.

상세 설명
JSON Toolbox는 별도 브라우저 탭과 웹페이지에서 오프라인으로 동작하는 빠른 JSON 포맷터, JSON 뷰어, JSON 비교 및 YAML 변환 도구입니다(JSONC·JSON5 지원). 설치 시 웹사이트 권한 요청이나 경고가 없으며 계정도 필요하지 않습니다.

포맷, 탐색 및 JSONC / JSON5
- 공백 2칸, 4칸 또는 탭 들여쓰기로 큰 정수와 소수 정밀도를 유지한 채 JSON을 정리합니다.
- 엄격한 JSON 파싱에 실패하면 주석, 후행 쉼표, 작은따옴표 문자열, 따옴표 없는 키, 16진수 정수를 포함한 JSONC / JSON5로 자동 폴백 파싱합니다.
- 구문 오류의 행·열 번호와 위치 이동을 표시하며, 브라우저가 위치를 제공하지 않으면 로컬 검증으로 보완합니다.
- 가상 스크롤 트리 보기, 단계별 펼치기, 키/값 검색 및 일치 항목 이동, 원클릭 복사를 지원합니다.

JSON <-> YAML 양방향 변환
- JSON을 YAML 1.2로, 또는 YAML을 JSON으로 변환하는 전용 페이지를 제공합니다(숫자 정밀도 보존, 다중 문서 YAML 지원, 순환·과다 별칭 차단).
- 클릭 한 번으로 변환 방향을 전환할 수 있습니다.

웹페이지 JSON 자동 포맷 및 우클릭 메뉴
- 웹페이지에서 텍스트를 선택한 뒤 우클릭으로 "JSON Toolbox에서 선택 영역 열기"를 누르면 즉시 포맷할 수 있습니다.
- 페이지 우클릭 메뉴 "이 페이지의 JSON 포맷"을 통해 별도 호스트 권한 없이 activeTab만으로 즉시 트리 뷰를 렌더링합니다.
- 사이드바의 "웹페이지 JSON 자동 포맷" 스위치는 기본값이 꺼짐입니다. 사용자가 직접 켤 때만 선택적 호스트 권한을 요청하며 원본/포맷 전환, 복사, 도구에서 열기 및 선택적 text/plain 옵션을 제공합니다.

로컬 파일 가져오기
- 일곱 개 도구 페이지 모두에서 파일 선택이나 끌어다 놓기를 지원합니다(.json 최대 50 MiB, YAML→JSON의 .yaml / .yml 최대 10 MiB, UTF-8).
- 대용량 파일이나 긴 텍스트는 편집기에서 바로 열려 전체 편집과 복사가 가능합니다.

압축, 이스케이프 및 JSON 비교
- JSON 한 줄 압축(JSONC/JSON5 지원), 문자열 이스케이프/복원을 제공합니다.
- 경로별 구조 비교(추가, 삭제, 값/유형 변경), 키 필드(id 등) 기반 배열 매칭, 경로 제외, 차이만 보기, 줄 단위 텍스트 비교를 지원합니다.

모양 및 개인정보 보호
- 사이드바에서 기본, 눈 편안함, 다크 테마를 선택할 수 있으며 페이지 뷰어에도 함께 적용됩니다. 로컬에는 테마와 text/plain 옵션만 저장되며 데이터 수집, 전송, 광고, 추적이 전혀 없습니다.

전체 입력과 결과는 메모리에 유지되며 성능은 기기와 데이터 구조에 따라 달라집니다. 가상 보기는 한 번에 내용의 일부만 렌더링하므로 브라우저 기본 찾기는 렌더링된 부분만 검색합니다. 필요하면 트리 검색을 사용하거나 전체 결과를 복사하세요. 차이가 많으면 일치하지 않는 텍스트 구간을 블록 단위로 표시할 수 있습니다.
