JSON Toolbox - Formatare, Vizualizator, Diff & YAML

Descriere scurtă
Formatare, vizualizare, diff JSON/JSON5 și conversie YAML locală. Suportă fișiere de 50 MiB și API offline, fără urmărire.

Descriere detaliată
JSON Toolbox este un instrument rapid offline pentru formatare JSON, vizualizator JSON, comparare JSON și conversie JSON în YAML, cu suport JSONC și JSON5 într-o filă dedicată. Nu solicită acces la site-uri la instalare, fără avertismente de permisiuni și fără cont.

Formatare, explorare și JSONC / JSON5
- Formatează JSON cu indentare de 2 spații, 4 spații sau tabulatori păstrând precizia numerelor mari și a zecimalelor.
- Comută automat de la JSON strict la JSONC / JSON5 pentru comentarii, virgule finale, ghilimele simple, chei fără ghilimele și numere hexazecimale.
- Afișează erorile de sintaxă cu linie, coloană și navigare la poziție și explorează arborele virtual cu căutare și copiere rapidă.

Conversie bidirecțională JSON <-> YAML
- Convertește JSON în YAML 1.2 și YAML în JSON păstrând precizia numerică, cu suport YAML multi-document și protecție împotriva aliasurilor excesive.
- Inversează direcția de conversie direct din interfață.

Formatare automată pentru pagini JSON și meniu contextual
- Selectează text pe orice pagină și alege din meniul contextual „Deschide selecția în JSON Toolbox”.
- Folosește la cerere „Formatează JSON de pe această pagină” prin activeTab fără permisiuni permanente.
- Comutatorul opțional „Formatează automat paginile JSON” din bara laterală este dezactivat implicit și cere acces opțional doar la activare, cu vizualizare Original / Formatat, copiere, deschidere în instrument și opțiune text/plain.

Import fișiere locale, minificare, escape și comparare
- În toate cele șapte instrumente importă fișiere UTF-8 (.json de până la 50 MiB; .yaml/.yml de până la 10 MiB în YAML -> JSON).
- Minifică pe o singură linie (inclusiv JSONC/JSON5), adaugă/elimină secvențe escape și compară structuri după index sau câmp cheie (id) cu ignorarea căilor selectate și diff de text.

Aspect și confidențialitate
- Alege Normal, Confort vizual sau Întunecat (sincronizat și cu vizualizatorul încorporat). Totul se procesează local în memorie: fără încărcări, cereri de rețea, reclame sau urmărire.

Intrările și rezultatele complete rămân în memorie; performanța depinde de dispozitiv și de structura datelor. Vizualizările virtuale afișează doar o parte a conținutului odată, astfel încât funcția de căutare a browserului acoperă doar partea afișată. Folosește căutarea în arbore sau copiază rezultatul complet când este necesar. În cazul diferențelor textuale ample, secțiunile care nu corespund pot fi afișate ca blocuri întregi.
