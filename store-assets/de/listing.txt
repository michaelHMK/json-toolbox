Name
JSON Toolbox - Formatter, Viewer, Diff & YAML

Kurzbeschreibung
Lokaler JSON- & JSON5-Formatter, Viewer, Diff und YAML-Konverter. Verarbeitet 50 MiB Dateien & API-Seiten offline ohne Tracking.

Ausführliche Beschreibung
JSON Toolbox ist ein schneller lokaler JSON-Formatter, JSON Viewer, JSON Diff und JSON-zu-YAML-Konverter mit Unterstützung für JSONC und JSON5 in einem eigenen Browser-Tab. Bei der Installation werden keine Website-Berechtigungen angefordert und keine Warnmeldungen angezeigt.

Formatieren, durchsuchen & JSONC / JSON5
- Formatieren Sie JSON mit 2 Leerzeichen, 4 Leerzeichen oder Tabulatoren und behalten Sie die genaue Präzision großer Ganzzahlen und Dezimalwerte bei.
- Bei strikten JSON-Fehlern greift automatisch ein fehlertoleranter JSONC-/JSON5-Parser (Kommentare, abschließende Kommas, einfache Anführungszeichen, unquotierte Schlüssel, Hex-Zahlen).
- Sehen Sie Syntaxfehler mit Zeile, Spalte und direkter Navigation zur Fehlerstelle sowie lokalem Positions-Fallback.
- Erkunden Sie einen klappbaren virtuellen Baum mit Ebenensteuerung, Schlüssel-/Wertsuche, Treffernavigation und 1-Klick-Kopie.

JSON <-> YAML Konvertierung
- Konvertieren Sie JSON in YAML 1.2 und YAML zurück in JSON unter Beibehaltung der Zahlenpräzision, inklusive Multi-Dokument-YAML-Streams und Alias-Schutz.
- Wechseln Sie die Konvertierungsrichtung direkt im Arbeitsbereich.

Webseiten-JSON automatisch formatieren & Kontextmenü
- Markieren Sie Text auf einer Webseite und wählen Sie im Rechtsklickmenü „Auswahl in JSON Toolbox öffnen“.
- Nutzen Sie bei Bedarf „JSON auf dieser Seite formatieren“ über activeTab, ohne dauerhafte Seitenberechtigungen zu erteilen.
- Der optionale Seitenleisten-Schalter „JSON-Seiten automatisch formatieren“ ist standardmäßig AUS; nur beim Aktivieren werden optionale Host-Rechte angefordert (inkl. Roh/Formatiert-Umschalter, Kopie, In Werkzeug öffnen und optionalem text/plain-Modus).

Lokale Dateien importieren
- Auf allen sieben Werkzeugseiten können Sie UTF-8-Dateien per Auswahl oder Drag-and-Drop importieren (.json bis 50 MiB; .yaml/.yml bei YAML -> JSON bis 10 MiB).
- Große Dateien oder lange Texte öffnen sich direkt im Editor zur vollständigen Bearbeitung und Kopie.

Minifizieren, maskieren & JSON vergleichen
- Einzeiliges Minifizieren (inkl. JSONC/JSON5), JSON-String-Escaping/Unescaping und detaillierter Strukturvergleich (Index oder Schlüsselfeld wie id, Pfade ignorieren, nur Unterschiede, zeilenweiser Textvergleich).

Darstellung & Datenschutz
- Wählen Sie Normal, Schonend oder Dunkel in der Seitenleiste (auch für den eingebetteten Viewer). Alle Daten werden ausschließlich lokal im Arbeitsspeicher verarbeitet – ohne Uploads, Netzwerkanfragen, Werbung oder Tracking.

Vollständige Eingaben und Ergebnisse bleiben im Arbeitsspeicher; die Leistung hängt vom Gerät und der Datenstruktur ab. Virtuelle Ansichten rendern jeweils nur einen Teil des Inhalts. Die Browsersuche erfasst deshalb nur diesen Teil. Nutzen Sie bei Bedarf die Baumsuche oder kopieren Sie das vollständige Ergebnis. Bei umfangreichen Textunterschieden können nicht übereinstimmende Abschnitte als ganze Blöcke dargestellt werden.
